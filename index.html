🔑 Tích hợp Đăng nhập một lần (SSO) cho Ứng dụng con

Khi nhân viên bấm [ MỞ ỨNG DỤNG ], Cổng thông tin tự động gắn mã xác thực ?sso_token=... vào URL của ứng dụng. Ứng dụng con chỉ cần dùng một trong hai đoạn mã dưới đây để nhận diện nhân viên mà không cần bắt đăng nhập lại:

1. Dành cho Web App HTML / JavaScript (GitHub Pages, Web nội bộ): 
<!-- Nhúng bộ SDK SSO của Long Khai Corporation -->
<script src="sso-client.js"></script>
<script>
  LongKhaiSSO.init({
    verifyOnServer: true,
    onAuthenticated: function(user) {
      console.log("Đã đăng nhập SSO:", user.maNhanVien, user.hoTen, user.phongBan, user.role);
      // Tự động điền thông tin nhân viên vào giao diện ứng dụng con tại đây
    }
  });
</script>
2. Xác thực trực tiếp qua API Cổng thông tin (POST / GET): 
// Đọc sso_token từ URL và xác thực với máy chủ Portal
const ssoToken = new URLSearchParams(window.location.search).get("sso_token");
fetch(PORTAL_API_URL, {
  method: "POST",
  headers: { "Content-Type": "text/plain;charset=utf-8" },
  body: JSON.stringify({ action: "verify_sso_token", data: { sso_token: ssoToken } })
})
.then(r => r.json())
.then(res => {
  if (res.success) console.log("Nhân viên:", res.user); // { maNhanVien, hoTen, phongBan, chucVu, role }
});
